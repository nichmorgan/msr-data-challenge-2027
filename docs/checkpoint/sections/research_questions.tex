\section{Research Questions and Related Work}

For the purpose of this paper, when we say "tools" what we means is dependencies and outside resources referenced in skills files. 
For example a react project may reference npm in the skills file, or an e-commerce platform may reference elasticsearch; both npm and elasticsearch would be treated as a "tool".

\subsection{RQ1: What are the most common tools mentioned in skills files?}

Our first goal is to compile a list of tools used by agent skills.
This research will help us understand what kinds of agent services skills files aim to direct.
Additionally, once we have a list of common tools it will be possible to perform additional analysis of the relationships between skills files and their tools.

The goal of this research question is to understand the relationship between the tools that skills files rely on, and the licenses of those tools.

\subsection{RQ3: What is the license distribution of the projects that host tools mentioned in skills files, grouped by the freedom each license provides?}

The goal of this research question is to understand the projects that host tools mentioned in skills files, and how the licenses of those projects are distributed when grouped by the freedom each license provides.
That freedom is what a license allows or denies doing with the project, so the distribution is oriented by those rights rather than only by license name.
Prior work has surveyed how developers view licensing and ownership when generative tools are used to write code~\cite{stalnaker2026developerperspectives}.
