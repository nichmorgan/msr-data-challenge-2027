\section{Dataset Overview}

The dataset we will be analyzing is the GitSkills dataset.
This dataset comes from a paper created by Giuseppe Destefanis, Daniel Graziotin, Matteo Vaccargiu and Marco Ortu.
Their paper proposes a dataset representing logs from 3,797,117 \texttt{SKILL.md} files from 282,200 repositories on GitHub~\cite{gitskills2027}.
The data was collected from GitHub throughout July 2026.
Artifacts in this dataset represent a single skill file, as well as associated metadata about its repository and referenced files.
A link to the paper may be found in the references section, or you may access it directly with \href{https://doi.org/10.1145/3136040.3136061}{this link}.

This paper will be referencing version 3 of the dataset published on September 11, 2026, 
the parquet file for which is available at their \href{https://huggingface.co/datasets/mvaccargiu/gitskills}{hugging face repository}.
