\section{Data Structure}

Each row in the dataset corresponds to a single skill referenced in the skills.md file.
For each entry,  the dataset contains the following fields:

\begin{itemize}
    \item \textit{Repository Name}: Name of the repository containing the skills.md file.
    \item \textit{Artifact Path}: Path to the skills.md file within the repository.
    \item \textit{Entry Name}: Assigned name of the skill
    \item \textit{Entry Type}: Type of the skill
    \item \textit{Entry Size}: Size in bytes of the body of the skill
    \item \textit{Entry SHA}: SHA hash of the entry (Identical entries will have the same SHA))
    \item \textit{Content}: Text in the body of the skill
\end{itemize}
