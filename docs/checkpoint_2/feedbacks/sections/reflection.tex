\section{Authors' reflection}
\label{sec:reflection}

We spent two weeks making a model extract taught tools from skill files, and before the peer review we had already started to discuss dropping that approach and labeling the tools by hand.
That path needs the steps below.

\begin{itemize}
  \item Find a sample size calculator, backed by a published source, that sets how many skills we need to label.
  \item Start with a small part of that sample, then return to review the labeling strategy.
  \item Find a labeling tool that keeps the labels in sync between members.
  \item Define the labels for tools and licenses, backed by a published source.
\end{itemize}

Because this discussion is still underway, we are not making the change in Checkpoint~2 or in this version of the paper.
