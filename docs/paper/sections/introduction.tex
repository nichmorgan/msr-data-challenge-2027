\section{Introduction}

A skill file tells a coding agent how to carry out a task, and its instructions can name outside products such as packages, developer tools, and hosted services.
GitSkills~\cite{gitskills2027} collects the public GitHub skill files written in Anthropic's agent-skill format as they stood in July 2026.
We use it to study which products these files teach agents to use and how the projects that publish those products are licensed.

This paper defines the study population, describes how taught tools are extracted, and presents the first checks of the data and of the extraction models.
Both research questions remain open, and Section~\ref{sec:future} describes the analyses required to answer them.
Our code and notebooks are kept in the study repository.\footnote{\url{https://github.com/nichmorgan/msr-data-challenge-2027}}
